# Instruções para agentes do projeto

- Os PRDs devem ser **sempre** criados na raiz do projeto atual, seguindo o formato `docs/plans/{{YYYY-MM-DD}}-{{descrição}}.md`.
- Ao criar ou atualizar um PRD, mantenha também uma cópia sincronizada em `PRD.md` para facilitar a consulta durante o desenvolvimento.
- Leia `PRD.md` e `SPECS.md` antes de alterar funcionalidades.
- Priorize acessibilidade, responsividade, linguagem apropriada para crianças e jovens e ausência de cadastro obrigatório.
- Não introduza monetização no MVP.
- Não afirme conformidade WCAG sem testes; registre limitações e testes pendentes.
- Prefira HTML semântico, CSS simples e JavaScript sem dependências externas.
