# Palavra do Dia — protótipo funcional

Projeto de jogo diário de adivinhação de palavras com três estilos visuais selecionáveis.

## Como executar

Abra `index.html` diretamente em um navegador moderno. Para APIs como compartilhamento nativo, é preferível servir por HTTPS ou por um servidor local estático. Não há build nem dependências de JavaScript externas.

## Arquivos

- `AGENTS.md`: instruções de trabalho.
- `PRD.md`: requisitos do produto.
- `docs/plans/2026-10-27-jogo-casual-adivinhacao-palavras.md`: PRD datado.
- `SPECS.md`: arquitetura, regras e plano de testes.
- `index.html`, `styles.css`, `app.js`: protótipo implementado.

## Limitações atuais

O vocabulário de demonstração é pequeno, os dados ficam apenas no navegador e não há backend ou sincronização. Os três estilos podem ser alternados na seção “Experimente os estilos”.
